Installer Moyennes pour PRONOTE

Le dossier téléchargé contient déjà l'extension prête à être sélectionnée. Aucun programme d'installation n'est nécessaire.

Gardez le dossier extrait. Edge utilise directement le sous-dossier extension : ne le déplacez pas et ne le supprimez pas après l'installation.
1

Repérez le dossier nommé extension

Dans le dossier que vous venez d'extraire, vous trouvez un sous-dossier nommé extension. C'est le seul dossier à sélectionner dans Edge.

Moyennes-pour-PRONOTE
  • extension dossier à sélectionner
  • GUIDE_INSTALLATION.html
  • GUIDE_INSTALLATION.md
  • README.md

Si vous ne retrouvez pas ce dossier, voici son emplacement exact sur votre ordinateur :

Sous-dossier extension

2

Ouvrez la page des extensions

  1. Dans Edge, cliquez sur le bouton Paramètres et plus (les trois points, en haut à droite).
  2. Choisissez Extensions.
  3. Cliquez sur Gérer les extensions.
3

Activez le mode développeur

En haut à droite de la page Extensions, activez l'interrupteur Mode développeur.

Mode développeur

Cliquez ensuite sur Charger l'extension décompressée.

Charger l'extension décompressée
4

Sélectionnez le dossier extension

Une fenêtre de sélection s'ouvre. Rendez-vous dans le dossier Moyennes-pour-PRONOTE que vous avez extrait, puis :

  1. Cliquez une fois sur le dossier extension pour le sélectionner.
  2. Cliquez sur le bouton Sélectionner un dossier.
Sélectionner le répertoire d'extension
Téléchargements > Moyennes-pour-PRONOTE
  • extension cliquez ici
  • GUIDE_INSTALLATION.html
  • README.md
Annuler Sélectionner un dossier

N'ouvrez pas le dossier extension : il suffit de le sélectionner. Ne choisissez ni le fichier ZIP, ni le dossier Moyennes-pour-PRONOTE.

5

Actualisez PRONOTE

Revenez dans PRONOTE, appuyez sur F5, puis ouvrez Notes > Les notes.

Installation terminée. L'encart « Moyennes estimées » apparaît au-dessus des notes. Il se mettra à jour automatiquement.

L'extension fonctionne uniquement sur votre ordinateur et n'envoie aucune donnée. Aucun fichier n'est copié ailleurs sur l'ordinateur.
